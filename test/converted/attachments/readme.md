# Attachments

The component displays attachments in the simple list. A user can remove attachments.

A value be `Array` in the form:

```
[
	{
		name: 'attachment.docx',
		url: 'url_to_download',
		size: 1024, // in bytes
		dtcreated: Date
	}
]
```
