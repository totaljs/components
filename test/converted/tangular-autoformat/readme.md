# Tangular-AutoFormat

This TAngular helper automatically formats email, phone number, boolean, numbers, dates or HEX color.

__Usage__:

```html
<h1>{{ name }}</h1>
<div>{{ source | autoformat }}</div>
```

or

```js
console.log(Thelpers.autoformat('https://www.totaljs.com'));
```
