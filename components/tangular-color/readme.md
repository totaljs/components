# Tangular-Color

A simple Tangular template engine __helper__ for rendering `colors` from the string.

__Usage__:

```html
<h1 style="color:{{ name | color }}">{{ name }}</h1>
<div style="color:{{ username | color }}">{{ username }}</div>
```
