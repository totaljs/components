# AI context for jComponent

Guides of the Total.js team for AI models about **using** the elements of the UI library in HTML. Copied from <https://github.com/totaljs/aicontext/tree/main/jcomponent> (and `component-development.md` from the Total.js team); update them from there. `component-development.md` mentions `jcomponent-components.md`, which is not part of this repository.

- [component-development.md](component-development.md): create a reusable component from a natural-language description (contract, hooks, data flow, verification); written by the Total.js team
- [ui-component.md](ui-component.md): initialize a component with `<ui-component>` (`name`, `path`, `config`, `default`, special `$` keys)
- [ui-bind.md](ui-bind.md): data binding with `<ui-bind>`
- [ui-import.md](ui-import.md): dynamic content with `<ui-import>`
- [ui-plugin.md](ui-plugin.md): scoped composition with `<ui-plugin>`

To **write** a component, see [../../SKILL.md](../../SKILL.md) and [../api.md](../api.md).
